# Amir Arshad

📦 I move freight for a living. 🌙 I build things for fun.

**Logistics professional by day · Hobbyist programmer by curiosity**

Diploma in Computer Science & Engineering · Govt. Polytechnic College, Kotdwar

I don't program because I have to — I program because I wonder *"Can I?"*

My projects don't always share a purpose or a programming language. Some explore astronomy, some experiment with graphics, and others solve problems closer to my everyday world. The common thread is simple: **curiosity, experimentation, and the joy of making things work.** 😄
